# Техническое задание на фотоматериалы

Все изображения в дизайн-пакете — пустые плейсхолдеры `<image-slot>` с описанием требуемого
кадра. **Ни одной реальной фотографии в пакете нет.** Этот файл собирает все слоты в одном
месте: что снимать, где это встанет, в каком размере и пропорции.

Документ служит двум целям одновременно: это ТЗ на съёмку для заказчика и перечень ключей
таблицы `content_slots`, из которого делаются сиды Фазы 2.

---

## Как читать

| Колонка         | Что значит                                                               |
| --------------- | ------------------------------------------------------------------------ |
| **Слот**        | ключ в `content_slots`, он же id из прототипа                            |
| **Где**         | конкретное место на странице                                             |
| **Пропорция**   | форма кадра, в которой изображение будет обрезано по `object-fit: cover` |
| **Мин. ширина** | ширина исходника; ниже неё на ретине будет мыло                          |

Кадр обрезается по `cover`, то есть **заполняет** контейнер и обрезается по короткой стороне.
Снимать с запасом по краям: то, что в макете видно как горизонтальная полоса, на мобильном
станет почти квадратом.

### Технические требования

- **Формат сдачи:** JPEG или PNG максимального качества, без ресайза и без обработки под веб.
  Сжатие в WebP делает система при загрузке — присылать оригиналы.
- **Цветовое пространство:** sRGB.
- **EXIF:** система удаляет метаданные при загрузке. Это осознанное требование — снимки
  паломников не должны нести GPS-координаты.
- **Ориентация:** горизонтальная везде, кроме двух фонов страницы выбора и мозаичных плиток,
  помеченных «вертикальный».
- **Люди в кадре:** для всех фотографий с узнаваемыми лицами нужно согласие на публикацию.
  Особенно это касается архивов групп паломников.

| ------------------------------------ | ---------------------------------------------- | ------ |
| **1 — без этого нельзя запускаться** | герои трёх сайтов, фоны страницы выбора        | 9      |

невозможно ни снять заново, ни заменить стоком. Если архива нет, раздел «Suratlar we wideo»
придётся запускать с теми группами, по которым материалы есть.

## 6. Пока фотографий нет

Все слоты заведены в базу как строки таблицы `content_slots` со статусом «не заполнено».
Каждая незаполненная позиция рисуется фирменной заглушкой, несущей собственный бриф, — сайт
собирается, показывается и обсуждается без единого настоящего снимка.

На время разработки слоты заполняются **временными стоковыми фотографиями** по этим же брифам.
Каждая такая помечена в базе как временная, и в админке есть отдельный список всех временных
изображений. **Выкладка в прод блокируется, пока этот список не пуст** — чтобы ни один
стоковый кадр не уехал на боевой сайт незамеченным.

Заменяются фотографии через админку перетаскиванием в нужный слот, без правок кода и без
перевыкладки.
