# Экраны — выжимка дизайн-пакета

Двадцать прототипов `design_handoff_charva/design/*.dc.html` разобраны здесь целиком, чтобы
больше никогда не открывать 250 КБ исходников. Данные, зашитые в прототипы, перечислены
полностью — из них строятся сиды Фазы 2.

Фотослоты вынесены в отдельный [photo-brief.md](photo-brief.md).

---

## 0. Как читать прототипы

`.dc.html` — DSL дизайн-инструмента. Соответствия:

| В прототипе                                         | В React                                                                |
| --------------------------------------------------- | ---------------------------------------------------------------------- |
| `<x-dc>`                                            | корень, ничего                                                         |
| `<helmet>`                                          | глобальный CSS                                                         |
| `<sc-for list="{{ xs }}" as="x">`                   | `xs.map(x => …)`                                                       |
| `<sc-if value="{{ cond }}">`                        | `{cond && …}`                                                          |
| `<dc-import name="Charva Nav" active="tours">`      | `<Nav active="tours" />`                                               |
| `style-hover="…"`                                   | правило `:hover`                                                       |
| `onClick="{{ fn }}"`                                | `onClick={fn}`                                                         |
| `class Component extends DCLogic`                   | функциональный компонент                                               |
| `renderVals()`                                      | мешок уже посчитанных строк стилей — в React это состояние плюс классы |
| `hint-placeholder-count`, `hint-size`, `data-props` | подсказки редактора, выбросить                                         |
| `<image-slot>`                                      | `<img loading="lazy" srcSet>`                                          |

**Во всём пакете ноль CSS-переменных** — каждый цвет инлайновый литерал. Имена токенов
существуют только в таблице README. Слой токенов пишется с нуля.

**Каждая страница имеет `min-width: 1280px`.** Медиазапросов нет ни одного, Choice ещё и
`min-height: 760px`.

`support.js` и `image-slot.js` не переносятся — см. [CLAUDE.md](../../CLAUDE.md).

**Формула цены — как есть в прототипе:**

```js
pax = /^\d+$/.test(people)
  ? parseInt(people)
  : people === '3–5'
    ? 4
    : people === '6–10'
      ? 8
      : people === '10+'
        ? 12
        : 2;
nights = { '3 дня': 3, '5 дней': 5, '7 дней': 7, '10 дней': 10, '14 дней': 14 }[dates] || 6;

    hotel
  ] || 78;
perPerson = nights * rate + dests * 60 + acts * 45 + 180;
total = perPerson * pax;
```

Формат: `String(Math.round(n)).replace(/\B(?=(\d{3})+(?!\d))/g,' ') + ' $'`.

падают в 2. На пустом выборе выходит `(6×78 + 180) × 2 = 1296` → **1 296 $ сразу при
загрузке**, и это намеренно. Ключи содержат настоящий `★` и **U+2013 en-dash** в «3–5» и
«6–10» — отсюда требование стабильных кодов (D-10).

will-change:flex-grow; transition:flex-grow 1100ms cubic-bezier(.16,1,.3,1)
